# Лаба4 Работа с файлами XML и JSON

## Задание

Создайте Django-приложение, которое может импортировать и экспортировать данные в форматах XML и JSON. Разработайте функционал для сохранения данных, введенных через html форму в файл формата XML или  JSON, а также загрузки файлов с данными и их последующего анализа и отображения на сайте.

Структуру данных для своего варианта придумать самостоятельно.

### Требования к заданию

- [ ] Реализовать возможность ввода данных через форму с дальнейшим сохранением в файл формата JSON/XML
- [ ] Реализовать проверку на валидность вводимых данных
- [ ] Реализовать возможность загрузки файлов формата JSON/XML на сервер  в определенную папку
- [ ] Реализовать проверку на валидность файла с данными при загрузке. Если файл не валиден то, вывести соответствующее сообщение и удалить его
- [ ] Реализовать возможность чтения и вывода на страницу браузера всех существующих файлов формата JSON/XML из соответствующей папки
- [ ] Реализовать проверку на существование файла/ов. Если ни одного файла на сервере нет, то вывести соответствующее сообщение.

### Варианты

7. Информация о музыкальных альбомах JSON.

## Настрока Django без Docker

### Настрока Питона

Сохраняем список всех установлинных в питон пакетов

```sh
pip freeze > requirements.txt
```

Устанавливаем в питон список пакетов

```sh
pip install -r requirements.txt
```

### Как создать новый серер

```sh
django-admin startproject server 
```

### Как создать модуль

```sh
python manage.py startapp module_name
```

### Кака запустить джанго

```sh
cd server

python manage.py runserver
```

### Запуск Докера композа

```sh
docker compose up
```

### Зайти в оболочку контейнера

```sh
docker exec -it container_name sh
# docker exec -it django-db sh
```

или

```sh
docker compose exec service_name sh
# docker compose exec db sh
```
